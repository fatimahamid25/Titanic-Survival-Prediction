# 🚢 Titanic Survival Prediction

A Machine Learning project that predicts whether a passenger would survive the Titanic disaster using passenger information.

## ✨ Features

- Passenger survival prediction
- Interactive Streamlit dashboard
- Data visualization and survival analysis
- Trained Machine Learning model
- Titanic-inspired dark teal interface

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Plotly

## 📂 Project Structure

```text
Titanic-Survival-Prediction/
│
├── app.py
├── test_model.py
├── titanic_final_model.pkl
├── titanic_processed.csv
├── requirements.txt
├── .gitignore
└── README.md
```

## ⚙️ How to Run

**1. Clone the repository**

```bash
git clone https://github.com/fatimahamid25/Titanic-Survival-Prediction.git
```

**2. Open the project folder**

```bash
cd Titanic-Survival-Prediction
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
streamlit run app.py
```

## 🧠 Machine Learning

The project uses a trained classification model to predict passenger survival based on selected passenger features.

The trained model is stored in `titanic_final_model.pkl`.
